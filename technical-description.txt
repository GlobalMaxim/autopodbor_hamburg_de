Упрощение: оставить две услуги, личный бренд, кейсы и переход в соцсети.
Без CRM, конфигураторов и лишнего функционала.

1. Цель проекта
Создать современный premium-сайт специалиста по подбору автомобилей в Германии.
Главная задача: показать экспертность → вызвать доверие → привести клиента
в личное общение через Telegram / TikTok / Instagram.

Сайт НЕ является: CRM, маркетплейсом, каталогом автомобилей, системой
онлайн-бронирования.

2. Услуги (две)

2.1. Проверка автомобиля под ключ
Клиент обращается по конкретному автомобилю. Специалист:
связывается с продавцом, организует осмотр, проверяет кузов/ЛКП, следы ДТП
и ремонтов, двигатель, КПП/АКПП, ходовую, электронику, диагностирует,
проверяет историю и пробег (если возможно), делает фото/видео, даёт
подробный отчёт и профессиональную рекомендацию.
Результат: клиент понимает, стоит ли покупать автомобиль.

2.2. Подбор автомобиля под ключ
Специалист: определяет требования → подбирает авто → ищет на немецком рынке →
отбирает лучшие → связывается с продавцами → проверяет историю и состояние →
организует проверки → сравнивает → ведёт переговоры → сопровождает покупку.
Результат: клиент получает авто без самостоятельного поиска и проверок.

5. Как это работает
01 Обсуждаем задачу → 02 Определяем требования → 03 Ищем / получаем авто
для проверки → 04 Проверяем → 05 Анализируем → 06 Даём рекомендацию →
07 Сопровождаем покупку.
Для подбора — дополнительно поиск и отбор автомобилей.

6. Кейсы
Кейс содержит: автомобиль, год, пробег, двигатель, коробка, цена, задача

Важно показывать авто, от покупки которых отказались — демонстрация
независимости эксперта.

личных кабинетов, регистрации/авторизации, онлайн-оплаты, booking, marketplace,
каталога авто, отправки ссылки на авто, URL-parser Mobile.de/AutoScout24,
AI-анализа объявления, risk calculator, отдельной услуги «разовый осмотр»,
WhatsApp как основного CTA.

18. Дизайн — Premium Automotive / Modern Editorial
Тёмный графит, белый, нейтральные оттенки, один акцентный цвет, крупная
типографика, качественные фото, много воздуха, минималистичные карточки,
сильные CTA.
Не: дешёвый авто-шаблон, glassmorphism, много градиентов, чрезмерные тени,
generic AI startup style, стоковые фото низкого качества.
Выглядит как персональный premium-сервис, не обычный автосервис.

19. Mobile First — mobile / tablet / desktop / large desktop.
На мобильном: удобная навигация, крупные CTA, быстрый доступ к соцсетям,
оптимизированные изображения и видео.

20. Производительность — Lighthouse 90+
Next/Image, lazy loading, responsive images, Server Components, минимум JS,
lazy loading видео, оптимизированные шрифты и изображения.

Keyboard navigation, labels, semantic HTML, contrast, focus states, alt,
prefers-reduced-motion.
