# Как добавить видеоотчёт по машине

## 1. Название отчёта (slug)

Придумай короткое имя файла: латиница, цифры, дефисы. Без пробелов, без заглавных букв.

Примеры: `bmw-x5-2021`, `audi-a6-2019`, `mercedes-e220d`.

Файл отчёта: `content/reports/<slug>.json`
Папка с фото: `public/reports/<slug>/`

## 2. Папка с фото

Внутри `public/reports/<slug>/` создай подпапки:

```
public/reports/<slug>/
├── main/        ← фото для галереи в шапке страницы (3–8 штук)
├── exterior/    ← Кузов
├── interior/    ← Салон
├── engine/      ← Двигатель
└── underbody/   ← Ходовая
```

Любую из `exterior/interior/engine/underbody` можно не создавать, если фото для неё нет — вкладка просто не появится на сайте.

Внутри каждой подпапки называй файлы цифрами с ведущим нулём — порядок на сайте будет таким же:

```
01.webp
02.webp
03.webp
```

Формат — **WebP**, длинная сторона ~2000px. Подойдут и `.jpg`, `.jpeg`, `.png`, `.avif`, но WebP легче и грузится быстрее.

## 3. JSON отчёта

Создай `content/reports/<slug>.json` по образцу (можно скопировать `example-bmw-x5.json` и поменять значения):

```json
{
  "draft": false,
  "service": "check",
  "inspectedAt": "2026-10-01",
  "title": "Audi A6 55 TFSI",
  "subtitle": { "ru": "2019 · 3.0 бензин · полный привод" },
  "priceEur": 38900,
  "specs": [
    { "label": { "ru": "Марка" }, "value": "Audi" },
    { "label": { "ru": "Модель" }, "value": "A6 55 TFSI" },
    { "label": { "ru": "Год" }, "value": "2019" },
    { "label": { "ru": "Пробег" }, "value": "78 000 км" }
  ],
  "videos": [
    { "provider": "bunny", "id": "abcd1234-...", "title": { "ru": "Диагностика сканером" }, "durationSec": 184 }
  ]
}
```

Подсказки по полям:
- `title` — марка и модель, одна строка, без перевода.
- `subtitle`, `specs[].label`, `specs[].value`, `videos[].title` — можно писать только `{ "ru": "..." }`, сайт сам возьмёт русский текст там, где перевода на другой язык нет. Если хочешь добавить перевод — допиши `"de"` и/или `"uk"` в тот же объект.
- `priceEur` — только число, без "€" и пробелов. Если цены нет — просто убери строку.
- `inspectedAt` — дата осмотра в формате `ГГГГ-ММ-ДД`.

### Где взять `id` видео в Bunny Stream

1. Зайди в панель Bunny Stream → нужная библиотека → видео.
2. Открой нужное видео, во вкладке "Overview" или в адресной строке найди **Video ID** (длинная строка вида `a1b2c3d4-...`).
3. Вставь это значение в поле `"id"` соответствующего видео в JSON.

Пока `"id"` пустой — видео на сайте показывается как заглушка (не кликается).

## 4. Публикация

Пока `"draft": true` — отчёт виден только тебе на локальном сервере (`npm run dev`), на сайте в продакшене его не видно (ни страницы, ни карточки в списке, ни в поиске).

Когда отчёт готов — поставь `"draft": false`, и он появится на сайте после следующей сборки/деплоя.

## 5. Как видео попадает в папку «Как мы проверяем»

На странице списка `/video-reports` есть блок с папками по темам (Проверка ЛКП, Работа со сканером и т. д.) — он собирается из `content/topics.json`. Материалы в папке берутся из двух источников:

**1. Видео из отчётов по машинам (через поле `topic`)**

Добавь в видео отчёта поле `"topic"` со значением `id` нужной темы из `content/topics.json`:

```json
{ "provider": "bunny", "id": "abcd1234-...", "title": { "ru": "Замер ЛКП толщиномером" }, "durationSec": 184, "topic": "lkp" }
```

Видео без `topic` просто не попадает в папку, но остаётся видно на странице своей машины — как обычно.

Значение `topic` должно совпадать с одним из `id` в `content/topics.json`, иначе `npm run build` упадёт с ошибкой и укажет, в каком файле опечатка.

**2. Фото из отчётов — автоматически, по названию подпапки**

У каждой темы в `content/topics.json` есть список `photoCategories` — это имена подпапок из `public/reports/<slug>/` (`exterior`, `interior`, `engine`, `underbody`). Если у темы, например, `"photoCategories": ["engine"]` — туда попадут фото из подпапки `engine/` **любого** отчёта. Ничего в самом отчёте настраивать не нужно.

**3. Собственные материалы темы — без привязки к машине**

Если у темы нет подходящего видео или фото из отчётов (или просто хочется показать что-то общее, не привязанное к конкретному авто) — добавь материалы прямо в `content/topics.json`:

- видео — массив `"videos"` у темы, в том же формате, что у отчётов (`provider`, `id`, `title`, `durationSec`, необязательный `poster`), только без `topic`;
- фото — положи файлы в `public/topics/<id>/` (имена файлов как в `public/reports` — `01.webp`, `02.webp`…), создавать запись в JSON для этого не нужно.

**Как добавить новую тему**

Допиши ещё одну запись в массив `content/topics.json`:

```json
{
  "id": "brakes",
  "title": { "ru": "Тормозная система" },
  "description": { "ru": "Диски, колодки, суппорты — замеры и визуальный осмотр." },
  "photoCategories": []
}
```

Порядок записей в файле = порядок папок на странице. Если у темы нет ни одного материала (ни своего, ни из отчётов) — на продакшене она просто не показывается; на локальном сервере (`npm run dev`) видна с плейсхолдерами, чтобы было видно, что тема существует, но пустая.

## 6. Как проверить, что всё правильно

Запусти в терминале:

```
npm run build
```

Если в JSON ошибка (опечатка, пропущенное поле, неверный формат даты) или в папке с фото лишняя/неправильно названная подпапка — сборка остановится и покажет, в каком файле и что не так. Поправь и запусти `npm run build` снова.
